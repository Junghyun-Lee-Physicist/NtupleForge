#     Run2017B  1208 Events / 269 HLT   calo b-tag paths, 'TripeCSV' typo
#     Run2017C  1523 / 479              PF CSV only
#     Run2017D  1570 / 526              PF CSV + PF DeepCSV
#     Run2017E  1612 / 526
#     Run2017F  1666 / 580
#     UL17 MC   1666 / 569
#
# Run B carries fewer than half the HLT paths of Run F and is the only era with
# the calo-based hadronic b-tag triggers the analysis ORs for that period.
